
## 11. Implementation Approval
- Before implementing any code changes, explain the proposed changes.
- Clearly identify affected files, features, and potential risks.
- Wait for explicit user approval before implementation.
- Do not modify, create, delete, or overwrite project files without approval.
- Suggestions and technical reviews do not require approval.
- If the user has not approved, provide explanations or plans only.
- Approval applies only to the specific changes described.
- Any additional changes require separate approval.
